# 创作者账号专业流程

使用当前集中资产库。先确认明确目标；用户允许自行选样时，可选公开知识账号并如实说明选择方法。使用宿主已安装的平台采集工具与真实返回值，不扫描私人账号资料，不猜字段，不读取不可见视频内容。

1. 采集主页、明确作品样本、发布时间、采集时间和范围。格式严格见工具仓库 `docs/runbooks/creator-distillation.md`，示例 `examples/creators/3blue1brown-capture.json`。
2. 字幕真实可得则保存时间段与正文，否则记录 unavailable 和实际原因；标题、简介、平台 AI 总结不能冒充视频字幕。
3. `vibe creator prepare <capture-json>` 冻结清单与专业方案。阅读完整任务，逐条分析并引用具体证据，区分作者声明、样本观察与推断；样本不足时缩小结论或输出空结果。
4. `vibe creator import <task-id> <analysis-json>` 校验入库。受众和候选模板标 interpretation，字幕结论必须引真实字幕正文；不以 URL、时间头或整个清单代替内容引文。
5. 用 Web 详情、MCP `get_creator_task` 与统一资产查询核对来源、版本和限制。实际采用后可显式写学习应用记录；没有执行的动作不要记录为已做。

MCP 保持只读。网页只提供准备、导入与消费，不代表存在后台模型。B 站字幕需要登录态而当前没有时，不获取或暴露凭据；保留缺失事实，继续完成允许的主页/作品元数据范围，并在交付明确未完成的视频内容分析。
