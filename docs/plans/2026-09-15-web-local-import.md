# Web 本地选择与炼化

## 需求和范围

用户已授权增加选择本地文件／项目文件夹后炼化的入口。复用现有工程和书籍分析器，源项目不复制、不修改。

采用页面内本地文件选择面板：从服务工作目录或用户主目录浏览，允许打开输入的目录路径，选择当前项目文件夹或 PDF/TXT/Markdown 文档。保留真实路径，避免浏览器上传丢失项目依赖。界面沿用现有纸张色和三栏布局。

## 契约

- `/api/import/browse`：POST `{ path }`，返回规范目录路径、父目录和目录/支持的文件条目。
- `/api/import/start`：POST `{ path }`，校验真实文件类型后启动独立 Node 子进程，复用 `distillProject` 或 `distillBook`。
- `/api/import/status`：GET，返回当前任务或 null。状态仅为 `running`、`succeeded`、`failed`；展示真实阶段，不伪造百分比。
- `/api/import/result/report`、`/api/import/result/assets`：GET，仅提供最近成功文档任务固定产物。
- 接口要求本机回环连接及页面提供的随机令牌，拒绝跨来源请求；不接受任意下载路径。每个 Web 服务同时只运行一个任务，完成后允许重试。状态在服务重启后清除，产物保存在原集中库。
- 工程成功刷新当前资产视图；文档提供报告预览和 JSON 下载，明确基础词表分析的能力边界，尚不新增统一书籍资产分类。
