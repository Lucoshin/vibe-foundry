# Web 空资产库正常布局

## 已确认需求

空资产库属于正常首次使用状态。保留导航、搜索、零值统计和详情待选提示，在列表区域说明如何开始。真实读取错误仍明确报告；不创建演示资产。

## 实现范围

- `src/web/asset-view-model.ts`：仅缺少集中库索引或空项目列表视为正常空库；已登记资产包读取失败仍报告错误。
- `src/web/frontend.ts`：在现有布局内展示空库引导，区分筛选无结果，空库报告页也显示引导。
- `tests/web/`：覆盖不存在的库、空索引、失效登记、损坏索引和前端空态行为。
- 沿用原有集中资产库契约、只读服务和真实错误页。不增加导入接口或兼容旧资产目录。

## 验收

运行定向 Web 测试、`npm test`、`npm run build`；重启 4317 服务，浏览器核验空库布局、分类和搜索。清理旧的“空库即错误”分支，保留真实错误处理。

## 验证结果

- Web 定向测试：48/48 通过；新增测试先复现空库误判与错误提示混淆，修复后通过。
- `npm test`：378/378 通过。
- `npm run build`：通过。
- Edge 实机：空库三栏布局、零值统计、开始使用说明、组件分类、搜索和报告空态通过；4317 服务已重启。
- 清理：删除集中库空态的错误分支及其重复返回结构，缩小缺失文件捕获到索引读取；保留单项目缺包、资产身份冲突和损坏索引的错误处理，避免把真实错误当成首次使用。
