# ADR-002：独立书籍炼化链路

## 背景

项目炼化器面向源码目录，短笔记隐喻分析器无法表达完整书籍的章节、概念和跨章节关系。

## 选项

- 把书籍转换为项目笔记后复用现有分析器：实现快，但会丢失章节和来源定位。
- 引入外部 LLM：语义能力强，但结果不可重复，并增加密钥和费用依赖。
- 新增确定性本地书籍分析器：能力有限但可测试、可追溯、无外部服务。

## 决策

新增 `distill-book`，第一版支持 PDF、TXT、Markdown。PDF 通过 `pdftotext` 提取；分析器生成章节、概念簇、关系和来源定位，不保存大段原文。

## 后果

概念识别依赖可扩展词表，不能替代人工精读。未来可在保持同一资产契约的前提下增加可选语义模型。

## 验证方式

运行单元测试、全量测试，并对《哥德尔、艾舍尔、巴赫》执行真实 `distill-book`。
