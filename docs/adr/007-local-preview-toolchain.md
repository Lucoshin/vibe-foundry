# ADR-007：预览工具随应用安装

## 背景

预览使用 npx 临时获取 Vite，首次展示依赖包管理器启动与网络环境；工具准备失败也被当作源码构建失败缓存。当前用户要求修复并缩短启动、导入后看到组件的等待。

## 决策

沿用现有选定版本，将 Vite 5.4.21、@vitejs/plugin-vue 5.2.4、sass-embedded 1.89.2 固定为 VibeFoundry 依赖。通过 process.execPath 和已解析的 Vite 入口执行，不经过 shell/npx；不改变用户项目的框架版本，源码运行依赖仍由源项目提供。

## 后果

首次安装体积增加；后续预览不再下载构建工具。动作摘要继续包含工具版本与 builder 源码摘要，升级后重新炼化产生新缓存动作。后台预热共享同一缓存，不另建缓存体系。

预览静态资源地址固定到构建动作摘要；CAS 内增加仅含组件 ID 与动作摘要的归属清单，读取旧版本时验证归属。最新组件入口保持不变，资源与挂载验证绑定同一动作，避免重炼期间混用不同版本。

## 验证

实际离线构建、真实浏览器展示、环境变量隔离回归、缓存重启复用；确认不再依赖 npx 或平台 shell 命令拼接。
