# 组件效果提示词验收

用户纠正了提示词的用途：帮助产品人员将喜欢的组件效果表达为专业设计需求，并明确选择按“布局、视觉、动效、交互”详细分项。已按[当前计划](../plans/2026-09-08-component-effect-prompts.md)替换上一轮源码打包式正文。

## 当前交付

- 默认正文是四项中文效果需求，描述实际可识别的结构、尺寸、排列、圆角、颜色、描边、投影、模糊、状态变化和动画参数。
- 不包含源码围栏、JSON 元数据或文件清单。分析依据和待核对项在 Web 独立折叠，复制只取正文。MCP 路径工具沿用，返回同一份记录。
- 记录升级为 `0.2.0`。旧源码版明确要求重炼，Web 返回 409，其他资产查询不受影响。`sourceFiles` 表示分析依据；`sourceDigest` 覆盖真实文本/二进制材料及生成结果，不仅是自然语言摘要。
- 已匹配的 CSS 状态会说明触发条件。只有事件绑定时不猜测点击后的业务结果；只有组件名或工具类名时不猜测毛玻璃、弹簧、磁吸等效果。

## 验证结果

`node scripts/verify-mvp.mjs` 通过：构建、319 个测试、51 个套件、0 失败；随后实际 CLI 炼化公开示例，并确认 MCP 提示词与磁盘完全一致，包含四个分项和真实文案，且不含源码。

结构与效果回归覆盖了局部绑定遮蔽、条件文本、不可达分支、HTML/ARIA 布尔值、React 无单位样式、外部 scoped 样式归属、动态属性展开，以及 CSS 匹配、状态条件、优先级、变量和关键帧。交叉检查的 React 卡片与 Vue 无样式按钮产生了不同描述，未混入无关样式，也未从名称编造效果。

插件 Skill 的 Python UTF-8 验证、脚本语法检查和 `git diff --check` 通过。没有对真实源页面执行视觉比较，也没有运行外部 AI 验证重建后的像素一致性。

## 速度与样例

运行 `node scripts/measure-component-distillation.mjs --output output/component-distillation`，React/Vue 各 20 个组件、20 个真实调用页和共享 CSS，结果如下。共享样式含悬停上移 4px、220ms 缓出过渡和键盘焦点外轮廓。

| 项目 | 首次炼化 | 未变化重炼 | 修改一个组件 |
| --- | ---: | ---: | ---: |
| React | 235.910 ms | 130.673 ms | 124.087 ms |
| Vue | 199.949 ms | 109.088 ms | 106.612 ms |
| 每组源码索引解析/复用数 | 40 / 0 | 0 / 40 | 1 / 39 |

这是 Windows x64、Node.js v24.12.0 上合成项目的单次观测，耗时包括完整炼化与写入，不含预览构建。源码索引的解析计数不包含效果描述所需的其他语法解析。两组均验证未变化摘要稳定、修改目标更新、无关组件不变。

生成示例：`output/component-distillation/component-effect-prompt.md`；原始数据：同目录 `component-distillation-benchmark.json`。该生成目录被 Git 忽略。

## 清理、保留和边界

清理了旧源码提示词模板、代码围栏函数、工程元数据正文拼接、旧入口文案、过时源码包含断言以及上一轮源码版示例文件。保留材料收集、解析缓存、预览材料摘要和精确组件寻址，因为它们仍支撑速度、来源与变更识别。历史验收文档标明已被当前目标修正，没有抹除旧验证记录；用户原有发布清单改动未修改。

当前为静态快速分析。未编译的工具类/预处理样式、不能确认的跨文件覆盖、复杂选择器和脚本驱动动效会留待核对。不会仅凭库依赖或类名推定视觉效果，实机观察与校准仍为后续范围。
